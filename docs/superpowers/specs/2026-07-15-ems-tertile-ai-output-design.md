# EMs 预后流水线统一三分位与 Illustrator 输出设计

## 目标

对 `01_EMs_ml_40395549` 建立一个统一的连续暴露分组合同：

- 最终 ML 特征中的4个连续变量全部进入 Cox。
- 所有变量统一使用三分位（T1/T2/T3），不再混用四分位和中位数。
- Cox、KM 和预后亚组复用同一组切点。
- 中介分析保留原始连续暴露，避免改变中介效应定义。
- 所有常规图同时输出 Adobe Illustrator 可编辑文字的 PDF 和 SVG。
- SHAP 图中的展示标签去除下划线。
- 修复 Figure 3 的 C/D 校准图为空。
- 清空该研究既有结果和检查点后，从头完整重跑。

## 分组合同

### 连续 ML 特征识别

从 `ctx$results$ml_feature_names` / `feature_selection_final` 读取最终 ML 特征。
连续变量定义维持为数值型且唯一值大于4。本研究当前对应：

- `Age`
- `Adhesion_Total_Score`
- `BMI`
- `Total_Tx_Duration`

`rAFS_Stage` 只有4个取值，继续作为分类变量，不纳入连续 Cox 批次。

### 三分位生成

新增通用的三分位切点生成逻辑，按样本分布计算：

- T1：最小值至第 1/3 分位
- T2：第 1/3 至第 2/3 分位
- T3：第 2/3 分位至最大值

所有4个连续变量必须使用相同的 `tertile` 方法。若某变量仍出现重复切点：

1. 连续尺度 Cox 结果必须保留；
2. 分组结果使用秩分组回退，尽量形成3个非空组；
3. 若数据本身不足以形成3组，明确报错，不能静默删除变量。

### 下游复用

- Cox：输出连续 HR、T1/T2/T3 HR 和趋势检验。
- KM：直接读取 Cox 保存的切点和 T1/T2/T3 标签。
- 预后亚组：连续暴露使用同一 T1/T2/T3 因子，不再按中位数二分。
- 中介：使用原始连续值；分类 ML 特征维持原水平。
- 敏感性分析和 Shiny 不改变其原有统计定义，但继承更新后的 ML/分组结果。

## 图形输出

### Illustrator 兼容格式

图形队列统一输出：

- PDF：矢量、`useDingbats = FALSE`、文字保持文本对象；
- SVG：使用 `svglite`，文字保持可编辑；
- PDF 与 SVG 使用相同尺寸、字体和展示内容。

多页亚组森林图：

- 保留一个多页 PDF；
- 每页另存一个 SVG（文件名后缀 `_p01.svg`、`_p02.svg` 等）。

若 SVG 依赖缺失，流水线应明确报错，不允许只生成 PDF 后声称完成。

### SHAP 标签

仅修改展示层：

- `Adhesion_Total_Score` → `Adhesion Total Score`
- `Total_Tx_Duration` → `Total Tx Duration`
- 其它标签同样将 `_` 替换为空格。

底层矩阵列名、模型特征名和 SHAP 对齐键保持原值，避免破坏模型预测。

## Figure 3 C/D 校准图

`PredictABEL::plotCalibration()` 返回的 `meanpred` 和 `meanobs` 已是百分比。
当前代码再次乘以100，导致点超出 0–100 坐标范围而被全部裁掉。

修复：

- 不再二次乘100；
- 在绘图前校验两列存在有限值且位于合理范围；
- C/D 至少包含对角参考线和一个模型的校准点/线；
- 若校准数据为空，Figure 3 构建失败并报错，不再生成空面板。
