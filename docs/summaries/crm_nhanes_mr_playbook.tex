\noindent
\textbf{一句话：}
观察端用 NHANES 加权分析回答「\textbf{血尿酸/高尿酸/痛风} 与 \textbf{共病负担CRM} 及 \textbf{全因死亡} 的关联」；
MR端用GWAS摘要统计回答「\textbf{SUA} $\rightarrow$ \textbf{CVD/CKD/糖尿病} 是否有因果证据」。
两套数据\textbf{解耦}：换观察病种不必换GWAS；换MR结局不必重跑NHANES。

\noindent\small\color{gray!40!black}
术语：\texttt{CRM\_count}=CVD+CKD+Diabetes计数（0--3）；本手册「共病孟德尔」指本套路，\textbf{不是}马尔可夫链模型。

\section{套路总览：在做什么}

\begin{enumerate}
  \item \textbf{共享派生}：NHANES宽表左连接死亡链接 $\rightarrow$ 入排（年龄等）$\rightarrow$ SUA/高尿酸/CRM组分/权重/随访时间。
  \item \textbf{obs\_main}：先做协变量筛选（univariate $\rightarrow$ VIF screen $\rightarrow$ multivariate $\rightarrow$ VIF final），再跑基线、有序OR、Cox HR、KM、RCS（Model2优先使用筛选结果）。
  \item \textbf{obs\_strata}：亚组OR/HR、死亡率补充表等。
  \item \textbf{mr\_*}：暴露IV筛选 $\rightarrow$ 与结局协调 $\rightarrow$ MR估计 + scatter/forest/LOO/funnel。
  \item \textbf{finalize}：白名单折叠为 \texttt{NHANES\_pub\_deliverables}（Table~1--3、S1--S11、Fig~1--2/S1、MR~S2--S13）。
\end{enumerate}

\section{换病 / 换指标：应准备什么数据}

\subsection{A. 观察端（换暴露指标或共病定义时）}

\textbf{必备文件}
\begin{itemize}
  \item 个体宽表（\texttt{.RData}/\texttt{.rds}）：一行一人，含唯一ID（如\texttt{SEQN}）。
  \item 死亡/随访表：可与ID左连接；至少 \texttt{mortstat}（或等价死亡指示）+ \texttt{permth\_int}（或随访月数）。
\end{itemize}

\textbf{必备列（名可映射，语义要对）}
\begin{itemize}
  \item \textbf{暴露}: 连续指标列（现默认\texttt{UricAcid}$\rightarrow$SUA）；可选自报痛风列（无则用代理切点，结果须标注局限）。
  \item \textbf{共病组分}（合成CRM）: 糖尿病指示；CVD相关指示（可多列OR）；肾功能（肌酐$\pm$年龄性别种族$\rightarrow$eGFR/CKD，或直接CKD列）。
  \item \textbf{调查设计}: 权重、\texttt{SDMVSTRA}、\texttt{SDMVPSU}（或等价）。
  \item \textbf{协变量}（亚组/调整）: 年龄、性别、BMI、吸烟、教育、收入等——按目标文献Model决定。
  \item \textbf{入排}: 年龄下界等（现$\geq$45）。
\end{itemize}

\textbf{换病时改什么（config，不改Blocks~01--69）}
\begin{itemize}
  \item \texttt{crm\_nhanes\_pub\$sua\_col} / 高尿酸切点 / \texttt{diabetes\_col} / \texttt{cvd\_cols} / CKD规则。
  \item 若CRM改为「其他三病组合」：改派生逻辑所读列，并同步flowchart/表题文案。
  \item 死亡结局若非全因：需有对应状态列，并改Cox/KM标签。
\end{itemize}

\subsection{B. MR端（换暴露GWAS或结局病种时）}

\textbf{必备文件}
\begin{itemize}
  \item \textbf{暴露GWAS}：全基因组或显著SNP摘要；推荐含 \texttt{rsid}/\texttt{hm\_rsid}、effect/other allele、beta、se、pval、eaf、N。
  \item \textbf{结局GWAS}：每个结局一个文件（如FinnGen/IEU）；列语义同上，可另存\texttt{outcome\_map}。
  \item \textbf{LD参考}：PLINK bfile（现用1000G EUR）+ \texttt{plink}可执行文件（用于clump）。
\end{itemize}

\textbf{换结局病时}
\begin{itemize}
  \item 在 \texttt{dual\_incidence\_mr\$mr\_outcomes} 与 \texttt{outcome\_map} 增删结局；准备对应gz/tsv。
  \item 清旧IV缓存或改 \texttt{iv\_cache\_path}；\texttt{--no-skip} 重跑对应 \texttt{mr\_*} unit。
\end{itemize}

\textbf{换暴露指标时}
\begin{itemize}
  \item 换 \texttt{gwas\_exposure} 路径与 \texttt{exposure\_name}/\texttt{exposure\_n}；重做clump缓存。
  \item 观察端暴露列与MR暴露\textbf{概念对齐}（同一生物学指标），但样本必须独立（两样本MR假设）。
\end{itemize}

\subsection{C. 明确不需要 / 常见误区}
\begin{itemize}
  \item MR\textbf{不需要}个体基因型或NHANES里的SNP。
  \item 观察端\textbf{不需要}日序列实验室轨迹（那是竞争风险套路）。
  \item 无真实痛风问卷时，\texttt{gout\_proxy\_sua\_cut} 会使「痛风$\times$正常尿酸」交叉为空——换病若依赖痛风分层，必须准备真实痛风列。
\end{itemize}
