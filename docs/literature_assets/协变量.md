
flowchart TD
    START([开始：单因素 → 单因素VIF → 多因素 → 多因素VIF]) --> POOL{多因素 VIF 池是否为空?}
    POOL -->|是| FB_POOL[工作池 = 单因素 VIF 池]
    POOL -->|否| MV_POOL[工作池 = 多因素 VIF 池]
    FB_POOL --> B1
    MV_POOL --> B1

    B1{多因素 VIF 池中有人口学?}
    B1 -->|是| M1A[Model1 = 多因素VIF 中的人口学]
    B1 -->|否| B2{单因素 VIF 池中有人口学?}
    B2 -->|是| M1B[Model1 = 单因素VIF 中的人口学]
    B2 -->|否| T3[三级回退]

    T3 --> M1C[Model1 = 单因素VIF 池全部非实验室变量]
    M1C --> M1D{Model1 仍为空?}
    M1D -->|是| M1E[从单因素VIF池随机抽取优先非实验室]
    M1D -->|否| M2T3
    M1E --> M2T3[Model2 = Model1 + 仅实验室指标实验室来自单因素VIF池]

    M1A --> M2STD[Model2 = Model1 + 多因素VIF池其余变量]
    M1B --> M2STD

    M2STD --> OUT([进入 Cox / Logistic 三模型分析])
    M2T3 --> OUT

    OUT --> CRUDE{Crude 显著但Model1/2 不显著?}
    CRUDE -->|否| DONE([沿用当前 Model1/2])
    CRUDE -->|是| RS{是否三级回退 tier?}
    RS -->|是| RS1[随机搜索：M1 从非实验室池抽样M2 仅追加实验室]
    RS -->|否| RS2[随机搜索：在 VIF 剩余池中向 M2 追加]
    RS1 --> DONE
    RS2 --> DONE
