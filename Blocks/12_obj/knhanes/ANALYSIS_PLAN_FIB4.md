# FIB-4 × 鼻窦炎（KNHANES）加权再分析方案

日期：2026-09-10
适用对象：现有未加权分析线（PSM + 条件 Logistic）的配套加权重分析

---

## 一、背景与目标

KNHANES 为多阶段分层整群概率抽样调查（stratified, multi-stage cluster probability sampling），
所有全国代表性推断必须使用抽样权重（weight）、分层变量（strata）、整群变量（PSU）：

- 未加权 → 点估计（患病率、OR）对全国人群有偏；
- 忽略设计 → 标准误系统性低估，P 值虚高、CI 过窄。

目标：产出一条与现有结果并行的"加权分析线"，作为修改稿的主分析，原 PSM/条件 Logistic
线降级为敏感性分析（或按审稿意见删除）。

---

## 二、路线选择（先定策略，再动手）

### 路线 A（推荐）：全样本设计加权回归，替代 PSM+条件 Logistic
- `survey::svydesign` + `svyglm`（quasibinomial），在 47,734 全样本上调整协变量；
- 权重与复杂设计本身就是处理抽样与混杂的规范做法，与 PSM 在方法学上相互独立、无需叠加；
- 与绝大多数已发表 KNHANES 加权论文口径一致，审稿争议最小。

### 路线 B（不推荐）：保留 PSM 框架再叠加权重
- 1:1 匹配后的条件 Logistic（`clogit` exact）没有支持抽样权重的标准方法；
- 权重进入 PS 模型/匹配距离的"加权匹配"在横断面配平场景缺乏成熟共识；
- 若强行做，只能说"匹配集内再按设计加权"，方法学站不住。

### 路线 C（退而求其次的兜底）：事后分层加权（post-stratification / raking）
- 若原始抽样信息无法回溯（见"三、关键卡点"），用外部人口结构（韩国统计厅单岁年龄×性别构成）
  对样本做 `svydesign(~1, weights=~w0)` + `rake()` 校准，近似全国代表性；
- 证据等级低于路线 A，只能作为过渡，须在 Limitations 中如实说明。

**建议：主线走 A，C 仅作 A 不可行时的备胎；B 不做。**

---

## 三、关键卡点：设计变量的可追溯性（必须先解决的审计项）

现有交付链在数据清洗时**丢弃了 SEQN、调查周期（cycle）、strata、PSU、weight**，只留下
自建 `ID`。实测发现：

1. ID 形态混杂：`101010302`、`1000020101`、`YR38376001`（带 YR 前缀的占位 ID）并存；
2. 分析集内 ID **重复 11 条**；
3. ID 疑似"周期代码+SEQN"拼接，但拼接规则未文档化。

处理步骤：
- [ ] 找回当初从 KDCA 原始文件（`*_1_data_info / *_4_examination` 等 per-cycle raw）提取数据
      的记录或脚本，确认 ID 生成规则；
- [ ] 逐周期重新提取：`SEQN, cycle, strata, PSU, weight`（各周期变量名不同，以 KDCA
      User Guide 为准；2016 年起部分周期改为**年度权重**，需先在周期内合并）；
- [ ] 按 ID ↔ (cycle, SEQN) 映射把设计变量并回现有 `D05_rt_CleanData`（47,734 例），
      核对匹配率；对 11 条重复 ID、YR 占位 ID 逐条定位来源；
- [ ] 无法回溯的样本（权重/设计缺失）：剔除并记录数量，进入 CONSORT 式流程图修改稿。

> 若原始提取数据已不可得，需要从 knhanes.kdca.go.kr 重新下载并组织"提取→拼接"这一步，
> 工作量最大，但这是唯一规范路径（路线 A 前提下）。

另需确认（影响哪些周期真正贡献样本）：
- 鼻窦炎问卷题（医生诊断询问）在各周期的模块与问题代码是否一致、起始年份；
- FIB-4 所需 AST/ALT/PLT 在健康检查组件中的可用周期；
- 1998/2001/2005（ periodic 期）设计变量与权重是否提供、可否与 continuous 期（2007/2008 起）合并。
  KDCA 不鼓励跨设计大合并时，考虑**仅纳入设计信息完整且问卷可比的周期**，并在方案中说明。

## 四、合并权重的构造

多周期合并（KDCA 通行做法）：

```
W_pooled(i) = W_cycle(i) × n_cycle(i) / Σ_cycle n_cycle
```

- 结局来自访谈问卷、暴露 FIB-4 来自血液检查 → 样本实际限定在"参加健康检查者"，
  **使用权重时以体检权重（examination weight）为标准做法**；
- 权重为 0 / 缺失的个体剔除；
- 构造后检查：权重极值（min/max/均值）、极大权重占比、设计效应 deff（`regTable`/`svymean` 对比
  简单随机假设的方差比），deff>2 需在结果中报告。

## 五、重分析流程（与现有 Step 目录一一对应，前缀 W_）

### W0 设计对象
```r
des <- svydesign(id = ~PSU, strata = ~strata, weights = ~W_pooled,
                 data = dt, nest = FALSE)   # pooled strata 全局唯一时
options(survey.lonely.psu = "adjust")
```
产出：加权患病率（对照未加权 8.2%）、样本量与权重摘要表。

### W1 加权 Table 1（替代现 Table 1 / S2 / S3）
- 全样本加权：连续 `svyby(~x, ~Disease, svymean/svyvar)`（Mean±SE 口径，注意不再是 SD 而是 SE，
  表注要改）；分类 `svychisq`（Rao-Scott 型）；
- 不再做 Before/After PSM 两栏，改"Overall (weighted)"单栏 + 未加权对比栏（放补充表）；
- 缺失值：插补仍可沿用 mice（未加权插补），或升级为加权插补（midge）；在 Methods 写明；
  Table S1（插补前后对比）保留原逻辑。

### W2 加权 Logistic（替代现 Table 2，主结果表）
- 暴露：FIB-4 连续（每 +1 单位 OR，必要时同时报 per-0.5 或 IQR 缩放）+ 四分位 Q1–Q4 + P for trend；
- **四分位切点用 `svyquantile` 重新计算**（不再沿用未加权 0.49/0.93/1.25，表注说明切点为加权）；
  或保留未加权切点以便与旧版可比 —— 二选一并写明，推荐后者用于对比、前者用于主表；
- 协变量三档与现稿完全一致，保证可比：
  - Crude：无调整
  - Model 1：Age
  - Model 2：Age + Waist, Height, Glucose, Hematocrit, TG, Cholesterol, Beta_Carotene, Urine_Protein, Vitamin_C
- `svyglm(Disease ~ ..., family = quasibinomial)`，输出设计稳健 OR + 95%CI + Wald P；
  trend 用组内序号赋值（说明其为近似检验）；
- 旧版"随机抽 8 个协变量凑显著"的逻辑**不要复用**——加权后直接采用 Model2 变量集一次跑通；
  若审稿要求，可补充正向逐步/全调整两套模型。

### W3 加权 RCS（替代现 Fig 2）
- `rms::lrm` 不支持设计权重 → 改用 `svyglm(Disease ~ rcs(FIB4, k) + 协变量, design=des)`
  （样条基用 `rms::rcspline.eval` / `Hmisc::lspline` 显式生成后进入公式）；
- 节点数 k=3–5 按设计版 AIC/BIC 或参照原稿 nk=3；
- overall / nonlinearity P：`anova(des对象, 项)` 的 Wald 检验（比较含/不含样条高阶项）；
- 拐点：在拟合曲线上反解 OR=1 的 FIB-4 值（沿用原 approxfun 方法），与未加权 0.76345 对比报告。

### W4 加权亚组森林图（替代现 Fig 5）
- 分层：Age（≤18 / 19–45 / >45）、BMI（<25 / 25–30 / ≥30）、Gender（FIB-4 连续口径）；
  层内设计对象用 `subset(des, ...)`，各层协变量 = Model 2 集（注意层内事件数，EPV<10 的层标注）；
- 交互 P：全模型中 暴露×分层变量 乘积项的 Wald 检验（svyglm 支持）；
- 出图格式沿用 gtsummary/jstable 森林图模板。

### W5 加权敏感性分析（替代现 Table S4/S5）
- 主敏感性 = 删除男性后重跑 W1–W2（与现稿口径一致）；
- 新增对照表：未加权 vs 加权 OR 并排（Table S8），直观回应"加权是否改变结论"；
- 视情况追加：剔除 2016 后年度权重周期 / 仅连续调查期（2008–2023）两套次级敏感性。

### W6 XGBoost / SHAP（Fig 3，保留不加权）
- 机器学习部分定位为"变量重要性探索"，不承担全国推断 → 维持未加权，Methods 加一句说明；
- 可选稳健性：`xgb.train(weight = W_pooled)` 再出一版 SHAP 排序放补充材料。

### W7 中介分析（Fig 6，Table S6/S7，维持现状 + 标注）
- 现有 mediation 包基于 PSM 匹配样本，加权中介需要边际结构模型/自然效应框架，成本高；
- 建议：维持原结果，在稿中明确标注为"探索性机制分析（未加权）"；
- 若审稿人坚持加权中介 → 另行立项做 IPW-MSM 版本，不承诺在本轮完成。

**Methods 增补（示例句）**：
> KNHANES 采用多阶段分层整群概率抽样。为保证全国代表性，所有推断性分析均使用 survey 包
> (R v4.x) 按 KDCA 指南构造合并权重（各周期权重 × 该周期样本量占合并样本的比例；暴露与结局
> 分别来自体检与访谈组件，故采用体检权重），并以分层-整群变量设定复杂抽样设计，
> 标准误采用设计线性化（或 Taylor series）估计。

**Limitations 模板**：
> 横断面设计不能推断因果与时序（"发病"应统一改为"患病"口径）；医生诊断问卷存在报告偏倚；
> 合并 19xx–20xx 年数据跨越问卷与设计调整，虽经加权仍可能残留时代异质性。

**一致性提醒**：现稿通篇是"发病/incidence"措辞，横断面 + OR 只能支持"患病/prevalence"，
趁本轮修订统一口径，可一并消掉一个常见审稿点。

## 七、执行顺序与工作量估计

| 阶段 | 内容 | 估计 |
|---|---|---|
| P0 | 路线拍板（A / A+C 兜底），确认原始提取记录可得性 | 0.5 天 |
| P1 | ID→(cycle,SEQN) 回溯审计 + 设计变量并回 + 权重构造质检 | 1–3 天（若需从 KDCA 重下载重建提取则 3–7 天） |
| P2 | W0–W2（设计对象、加权 Table1/Table2） | 1 天 |
| P3 | W3–W5（RCS、亚组、敏感性 + S8 对照表） | 1–1.5 天 |
| P4 | 图表重绘（沿用现有样式模板）+ 报告文字更新 | 1 天 |
| P5 | 未加权/加权结果一致性核查、异常（权重集中、deff 过大）处理 | 0.5 天 |

**最大风险 = P1**：设计变量能否逐周期回溯。建议第一时间先做 2 小时可完成的小审计：
取任意一个周期原始文件，验证 SEQN→strata/PSU/weight 与现有 ID 的映射规则；
跑通 1 个周期再全量展开。

## 八、需要用户确认的决策点

1. 加权线是否作为主分析（替换 PSM 线），还是与 PSM 线并列双报告？
2. 手头是否保留各周期 KDCA 原始下载文件 / 提取脚本（决定 P1 是 1 天还是 1 周）；
3. 跨 1998–2023 合并的周期取舍：是否接受"仅纳入设计信息与问卷口径完整的周期"（如连续调查期），
   从而可能改变总样本量与全部既有数字；
4. 中介与 XGBoost 是否接受"维持未加权 + 标注探索性"的处理。
