# 主库 / 验证库 + 扩展分析设计（血脂异常 × 睡眠 × 全因死亡）

日期：2026-10-26  
项目：`prognosis_v2_41904528`

## 1. 角色

| 队列 | 角色 | 用途 |
|------|------|------|
| NHANES | 主库 | 定协变量、主效应、RCS 切点、5/10 年预测、465 分钟临床包 |
| SHHS | 主库 | 与 NHANES 共同定协变量；独立重复主效应与扩展分析 |
| CHARLS | 验证库 | 用主库协变量集做外部验证；不参与定模；不做 5/10 年预测 |

原则：

- 图和表**种类不删**；主库 / 验证库在脚注标明角色。
- Table 1 **不再要求三库变量完全一致**；CHARLS 可按本库可得变量描述，但主分析协变量集以 NHANES∩SHHS 为准。
- 不把 CHARLS 事件少当成“再挖协变量”的理由。

## 2. Model 3（主库定，全新重跑，不手工点名）

- 在 **NHANES、SHHS** 上重跑 Boruta；取两库 **Confirmed 交集**（去掉 Age/Gender/Sleep_hours）。
- 仅在主库上算 VIF，&lt;5 保留。
- **不因 CHARLS Rejected 删变量，也不预先规定必须含糖尿病。**
- CHARLS 只用定好的同一套 Model 3 做验证。
- Model 1 不调整；Model 2 = Age + Gender。

旧三库平权结果已归档，本设计对应新目录 `prognosis_v2_mainval_41904528`。

## 3. 睡眠暴露（保留 + 新增）

**主分组（保留）**：`<7 h` / `7–8 h`（参照）/ `≥9 h`

**新增对比**（完整病例、Model 1–3，主库必报，CHARLS 验证）：

- `<6 h` vs `≥6 h`（或 vs `7–8 h`：采用 **vs 7–8 h**，与主表同一参照，便于对读）  
- `<5 h` vs `7–8 h`

实现：在同一分析样本中构造指示变量，参照仍为 7–8 h；`<5` 是 `<6` 的子集，需在表注写明样本量（SHHS `<5` 约 93 人，事件可能很少）。

## 4. RCS cut-off

- 主库 NHANES：与表 3 一致的加权样条（至少报 Model 1 与 Model 3）。  
- 主库 SHHS：未加权同样条。  
- 验证 CHARLS：未加权，仅描述。  
- 切点规则（预指定，不挑显著）：
  1. 网格上 **HR 最小点**（最低风险睡眠小时）；  
  2. 若存在多个 HR=1 交点，报告最靠近 7–8 h 的交点。  
- 产出：切点表 + 按“&lt;切点 / ≥切点”的 Model 3 Cox（主库；CHARLS 验证）。  
- **不替代**主三分组。

## 5. 5 年 / 10 年死亡预测

- 仅 **NHANES、SHHS**。  
- 模型与现 2 年一致：`glm(death_by_t ~ Sleep_hours + Age + Gender)`；NHANES ROC 可加权。  
- 产出：AUC、Youden（预测概率切点）、灵敏度、特异度；可增补图或附表，**保留原 2 年表图 5 / 表 S4**。  
- CHARLS：脚注写最长随访约 2.63 年，无法做 5/10 年。

## 6. 465 分钟（7.75 h）临床意义包

切点固定 **465 min = 7.75 h**（外部/既往临床切点，不作数据挖矿）。  
暴露：`Sleep_hours < 7.75` vs `≥ 7.75`（短于切点为暴露侧，与既往“短睡侧”叙述一致；若既往定义相反，表注写清）。

| 模块 | 内容 | 库 |
|------|------|-----|
| 关联 | Model 1–3 Cox | 主库 + CHARLS 验证 |
| 人群归因危险度 PAR | Levin：\( \frac{p(RR-1)}{1+p(RR-1)} \)；RR 用 Model 3 HR；NHANES 的 p 用加权暴露率 | 主库；CHARLS 粗算标验证 |
| 诊断效能 | 单独用 `<7.75 h` 预测死亡的 Se/Sp/AUC（粗）；另报年龄+性别+睡眠的时点 AUC 作对照 | 主库 |
| 额外检出率 | 在年龄≥60 或高血压已标记的高危之外，短睡额外覆盖的死亡比例 | 主库 |
| 联合分层 | 睡眠×年龄（&lt;60/≥60）、睡眠×高血压：人数、死亡、人年率；可选层内 HR | 主库 |
