## 6. Required Fixes

1. **【高优先级】拆分「可直接复用」**：将 N1、N2、N5 的「可直接复用」改为「条件性复用——需先检查暴露定义、结局时间窗、PS 变量、双库合并策略」。在 N0 与这些节点之间插入「迁移前提检查」节点（如 MB1–MB4 的条件分支）。

2. **【高优先级】结局定义分支**：在 N0 后设计明确分支——若 28d 固定随访无删失 → 用 logistic；若存在删失或想保留时间信息 → 用 Cox。此分支影响 N1、N5 的模型选择，必须在树中显式表达。

3. **【高优先级】双库合并路径**：在 N7 中给出具体方案——分库估计 PS（每库 logistic → 各自 IPW → 合并分析）、库作为协变量、或合并后统一 PS。这 3 个选项要求敏感性比较，且根据库间变量分布差异选择。

4. **【中优先级】PE 特异变量与 PS 清单**：在 N3 与 N1 中加入 PE/ICU 变量的候选清单：血流动力学（收缩压、心率、呼吸频率、氧饱和）、右心负荷（肌钙蛋白、BNP、超声 RV/LV）、sPESI/PESI、合并症（活动性出血、恶性肿瘤、近期手术）、体重/肾功能。若某些变量在库中缺失，标注「敏感性分析或放弃该变量」。

5. **【中优先级】暴露时间窗与 immortal time 检查**：在 N1 前加分支：若 alteplase 在随访起点后使用（如入院后数小时），须 landmark（如以给药时间或入院后 24h 为起点）或使用时变暴露；否则 IPW 结果会混入存活偏倚。

6. **【中优先级】拓扑结构调整**：N6 不再与 N0 直接相连，而是接到方法节点（如「若 IPW 不可行 → 局限与替代方法」）；N9 并入 N3，避免节点重复；N8 标记为 user_input。
