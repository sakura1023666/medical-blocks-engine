# 第 8 章 医学/流行病学文献 — 对抗式阅读决策树问题模板（医学改编版）

> 本文件是原操作手册第 8 章「无人机声源定位」八问的**医学/流行病学改编版**，用于驱动 AI-A（读者）生成针对临床与流行病学文献的「分析决策树推理」，再由 AI-B（评审）对抗打分。
>
> 每篇文献按「建议跑法」选问，**一篇文献 × 一道选定问题** → 生成一条 JSONL 训练样本。

---

## 8.1 八问对照表（医学改编版）

| 问题编号 | 问题 | AI-A 决策树应该重点判断 |
|---|---|---|
| **Q1** | 本研究**预设了几个分组 / 亚型 / 类别**？该数量是数据驱动的（如聚类定 K、LCA 类数比较）还是研究者主观指定（如已暴露 vs 未暴露、病例 vs 对照）？是否假设了暴露-结局关系的**方向**（线性、单调、U 型）？ | 1) 分组/类别来源：**数据驱动**（K 由轮廓系数/BIC/silhouette 选定）还是**先验指定**（基于临床/暴露定义）；2) 是否预先声明了关系形态（线性/非线性/U 型/阈值）；3) 若先验指定，**依据是什么**（临床指南、既往文献、还是方便取样）。决策树根部应区分「假设形状」分支。 |
| **Q2** | 如何处理**多亚型 / 多终点 / 多层暴露**？（如多个炎症标志物、多个结局：全因死亡 vs 心血管死亡；多个随访时点）是否会因**多重比较**膨胀 I 类错误？是否对相关终点做了主成分/复合终点聚合？ | 1) 是否区分**主终点**与**次要终点**，主终点先报、次终点标注探索性；2) 多重比较校正策略（Bonferroni / FDR / 假设族预先界定 / 不校正并说明）；3) 多标志物是否合并为指数/复合指标以减少维度；4) 决策树应含「终点数>1」→ 校正分支。 |
| **Q3** | 该方法/模型与**既有方法**的区别在哪？对照：**逻辑回归 / Cox 比例风险 / 倾向性评分（PSM/IPTW）/ 潜在类别分析（LCA）/ 传统聚类（K-means、层次）/ 其他机器学习（随机森林、XGBoost、深度学习）**。本研究为何选此法而非彼法？换一种方法结论会变吗？ | 1) 选定方法相对于**最直接替代法**的核心差异（参数假设、对非线性/交互的捕捉、可解释性 vs 预测力）；2) **稳健性检验**是否换方法复核（如 Cox 之外加竞争风险、PSM 之外加 IPTW、聚类之外加 LCA）；3) 若换了方法结论是否仍成立（方向、显著性、效应量）——决策树须含「方法替换敏感性」节点。 |
| **Q4** | **变量/协变量筛选与建模逻辑**是什么？（变量入模的依据：临床重要性 / 单因素 p 值 / 文献 / DAG / VIF；模型形式：加性 / 含交互 / 含非线性项 RCS；是否做了变量选择如 LASSO、逐步回归）该逻辑是否在分析前预先确定？ | 1) 入模依据分类并排序：**DAG/临床先验 > 文献 > 单因素 p 阈值（注明阈值如 p<0.1）** > 自动选择（LASSO/逐步，须报 lambda/方向）；2) 是否考虑**交互项**与**非线性（RCS/样条）**，依据是否充分；3) 是否做了**多重共线性筛查（VIF）**；4) 决策树应分叉为「变量进入」→「模型形式」→「共线性处理」三段。 |
| **Q5** | 该分析**依赖哪些参数假设**？是否满足？（Cox 的比例风险假设、logistic 的线性 logit、正态性/方差齐性、聚类数 K、LCA 的局部独立性、ML 的训练/验证划分与超参数调优）。若是**复杂抽样/加权设计（NHANES 等）**：是否正确使用了**抽样权重、PSU、分层（survey-weighted 估计）**？是否处理了**缺失（多重插补 vs 完整病例）**？ | 1) 逐一列出**关键假设**及检验方法（Schoenfeld 残差验 PH、VIF 验共线性、Box-Tidwell 验 logit 线性等）；2) **NHANES/加权设计**专项：权重变量、`svydesign/svyglm`、自由度近似、多年份权重合并规则；3) 缺失机制假设（MCAR/MAR/MNAR）与处理方式；4) ML：训练/测试/验证划分、超参数网格、是否过拟合（CV/OOB/外部验证）。决策树须含「假设检验不通过」→ 备选分支。 |
| **Q6** | 论文**如何证明分析有效**？（内部验证：AUC/C-index、自举法 bootstrap、交叉验证；外部验证队列；敏感性分析：剔除高影响点/改变模型形式/改变权重；阴性对照；E-value 评估未测混杂）。证据强度如何？ | 1) 区分**区分度**（AUC/C-index）、**校准度**（校准曲线/Hosmer-Lemeshow）、**内部稳定性**（bootstrap、CV、10 折）；2) 是否有**外部/时间验证**；3) 敏感性分析的**数量与方向覆盖**（剔除关键变量、改权重、改模型、限制子样本）；4) 是否用 **E-value / 阴性对照**量化未测混杂的稳健性。决策树应含「有效性证据层级」分叉。 |
| **Q7** | **局限**有哪些？（残余混杂/未测变量、选择偏倚/失访、因果倒置、队列外推性、ML 可解释性与可重复性、加权设计的方差膨胀、中介分析的时序假设）。这些局限是否被合理讨论，是否影响主要结论的方向？ | 1) 每条局限**定性影响方向**（高估/低估/方向不明）；2) 哪些局限作者**已用方法缓解**（如 PM 缓解指示混杂、IPTW 缓解已知混杂、三角法辅助因果）；3) 哪些是**无法缓解的**（未测混杂、单时点暴露、横断面无法定时序）；4) 综合判断：局限是否动摇主要结论。决策树须有「局限 → 结论可信度」连接。 |
| **Q8** | 该文的**方法与套路**中，哪些**可迁移到「我的研究」**？（我的研究：____方向____；数据是否含相似结构：纵向随访/横断面加权/亚型聚类/中介路径）。哪些步骤可原样套用，哪些必须按我的数据改写（变量名、权重、K 值、随访定义）？ | 1) 明确**我的研究类型**与本文的差异（暴露、结局、设计、抽样）；2) 哪些**统计套路可平移**（如加权 Cox、RCS、LCA、中介三步法、ML 子型发现）；3) 哪些**必须重新适配**（变量映射、权重合并、K 重选、训练集划分）；4) 决策树应分叉到「可直接复用 / 需改编 / 不适用」三类。 |

> **Q8 使用说明**：「我的研究」方向需由用户（pipeline 使用者）在调用前**自行确认并填入**，AI-A 不得臆测；若用户未提供，AI-A 应在 Q8 输出中显式标注「用户研究方向未确认，以下为泛化迁移框架」。

## 8.3 建议跑法（医学改编版）

> 每篇文献**默认先跑 Q1、Q2、Q4、Q5、Q8**（分组假设、多终点、变量/建模逻辑、参数假设、可迁移性）——这五问覆盖任何临床/流行病学论文的方法骨架。
>
> - **综述/方法比较类**或方法学对比鲜明者，加 **Q3**；
> - **验证证据充分**者（含内部/外部验证、敏感性分析），加 **Q6**；
> - **高度相关**或局限影响主结论方向者，加 **Q7**；
> - **ML/亚型发现类**（paper_002）必须加 **Q6**（验证与可重复性）与 **Q3**（与既有聚类/LCA 区别）；
> - **加权设计类**（paper_003）必须在 **Q5** 中显式覆盖权重/PSU/分层，并加 **Q7**（横断面因果局限）。
>
> 每条 JSONL 样本：**一篇文献 × 一道选定问题** → AI-A 产出 rejected/chosen 双决策树 + 证据 + 评分。**Q8 须在用户确认研究方向后再生效。**
